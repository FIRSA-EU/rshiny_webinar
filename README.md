# Building Dashboards with R Shiny

This repository contains the slides and teaching materials for the FIRSA webinar **Building Dashboards with R Shiny**.

The slides introduce the basic structure of an R Shiny application and explain how dashboards can be used for research communication. The session covers the relation between the user interface and the server, basic inputs and outputs, simple layouts, deployment, and examples of research dashboards.

## Files

- `index.qmd` — source file for the Quarto RevealJS slides
- `index.html` — rendered slide deck
- `firsa.css` — custom CSS styles and FIRSA branding
- `references.bib` — bibliography file
- `figures/` — images and visual material used in the slides
- `index_files/` — rendered slide dependencies generated by Quarto

## What the slides cover

The webinar introduces the basic logic of Shiny apps in R. It explains how the user interface defines what users see and control, while the server defines how R responds to those inputs.

The slides use a simple Palmer Penguins example to show how inputs can filter data, update plots, display summary text, and render a table inside a web app.

## Requirements

Main R packages:

    shiny
    palmerpenguins
    dplyr
    ggplot2
    DT

Install them with:

    install.packages(c("shiny", "palmerpenguins", "dplyr", "ggplot2", "DT"))
